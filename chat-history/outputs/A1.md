## 1. What is Node.js?

Node.js is an open-source **JavaScript runtime environment** that executes JavaScript code **outside of a web browser**. It was created by Ryan Dahl in 2009.

### Key facts

- **Built on Chrome's V8 engine** — JavaScript is compiled to native machine code, so it runs fast.
- **Event-driven, non-blocking I/O** — instead of waiting for a file read or database call to finish, Node handles other requests and resumes when the result is ready. This makes it efficient for concurrent connections.
- **Single-threaded (with a twist)** — the main event loop is single-threaded, but heavy work (file I/O, network, crypto) is offloaded to a libuv thread pool. Since Node 10 there is also a `worker_threads` API for true multi-threading.
- **npm (Node Package Manager)** — the largest software registry in the world; millions of open-source packages are installable with one command.

### What it's used for

- **Backend/web servers** (Express, Fastify, NestJS)
- **REST APIs and GraphQL services**
- **Real-time apps** (chat, collaboration tools) via WebSockets
- **CLI tools and developer tooling** (Vite, ESLint, and most modern front-end build tools run on Node)
- **Serverless/edge functions**
- **Full-stack JavaScript** — one language (JS/TS) across frontend and backend

### What it's NOT

- It is **not a programming language** — it runs JavaScript.
- It is **not a framework** — frameworks like Express build *on top of* it.
- It is **not limited to web development** — file processing, scripting, and embedded uses are common.

### Simple mental model

```text
Browser:   HTML/CSS/JS engine = V8 + Web APIs (DOM, fetch, ...)
Node.js:   V8 + system APIs   (filesystem, network, processes, ...)
```

Same language, different environment: the browser gives you a DOM; Node gives you the operating system.
