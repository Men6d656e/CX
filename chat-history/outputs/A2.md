## 1. Build the vite_express_web app (backend + frontend + README)

Built inside the `apps/vite_express_web` submodule. Both halves verified working.

### Backend (`backend/`, Express + ES modules, nodemon)

```
backend/src/
├── config/env.js               ← loads PORT, LOGIN_EMAIL, LOGIN_PASSWORD
├── models/db.js                ← in-memory sample db = source of truth
├── controllers/authController.js
├── controllers/postController.js
├── routes/authRoutes.js        ← POST /api/login
├── routes/postRoutes.js        ← GET/POST/PUT/DELETE /api/posts
├── app.js                      ← express app, cors, 200kb json limit
└── server.js                   ← listens on PORT
```

- Login: extracts email+password from the body, matches against `.env`, responds with a bcryptjs hash. No register route.
- Posts: title, description, image (small base64 string stored as-is). Full CRUD, separate route/controller files per professional discipline.
- `bcryptjs` used instead of native `bcrypt` (npm blocked the native install script; same API).

Smoke-tested: login ok, wrong credentials → 401, posts list/create/update/delete all pass.

### Frontend (`frontend/`, Vite + React + Tailwind v4)

- `LoginPage` — posts credentials to `/api/login`, stores the returned hash.
- `PostsPage` + `PostCard` + `PostForm` — list, create, edit, delete posts; image files converted to base64 data-URLs client-side before send.
- `npm run build` passes clean.

### README

Full setup/run docs written to `vite_express_web/README.md` (root of the submodule).

Run: `cd backend && npm run dev` (port 4000), `cd frontend && npm run dev` (port 5173).
