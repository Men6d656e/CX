## 1. Serve the built frontend from the backend at `/` (prod mode) + dev-mode split

Done in the `apps/vite_express_web` submodule.

### Backend now serves the frontend

`backend/src/app.js` resolves `../frontend/dist` and, when it exists:
- `express.static` serves the built assets,
- a catch-all `GET *` returns `index.html` (SPA fallback).

API routes (`/api/*`) are matched first, so they're unaffected.

### Scripts (`backend/package.json`)

- `npm start` — **production, one command**: builds the frontend (`npm run build --prefix ../frontend`) then runs the server. UI + API both on `http://localhost:4000`.
- `npm run dev` — **development**: `concurrently` runs backend (nodemon, 4000) and frontend (Vite, 5173) together.
- `npm run dev:backend` — backend only.

### Verified

`npm start` → frontend build succeeds, `GET /` returns the app HTML, SPA routes return 200, `GET /api/posts` still works.
