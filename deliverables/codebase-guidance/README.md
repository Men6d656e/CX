# Codebase Guidance — the 4 docs (0→100%)

These four documents are the COMPLETE guide from zero to a finished codebase.
A developer reading only these files must be able to build the app without
asking a single question. If a question still comes up: fix the doc, don't
answer privately.

| File | Answers | Done when |
|------|---------|-----------|
| `01-srs.md` | WHAT to build and for whom | every feature has acceptance criteria; out-of-scope list present |
| `02-sdd.md` | HOW it is structured | architecture + module diagrams; every tech choice has a reason |
| `03-test-plan.md` | HOW we know it works | every feature has test cases + expected results |
| `04-api-data.md` | The concrete contracts | all endpoints, schemas, env vars specified |

Completed (all 4) → one `codebase-guidance-docs` contribution record, or one
`codebase-guidance-doc` record per doc if built by different members.
